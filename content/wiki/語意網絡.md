## 語意網絡概述

**語意網絡**（Semantic Network）是符號式人工智慧中一種重要的**網絡表示**方法，旨在於電腦中以圖形方式重現人類腦中互相關聯的概念網絡。人類在思考時，往往會將各種概念、物件與屬性連結成龐大的心智模型，而語意網絡正是透過圖論中的節點與邊來模擬這種結構。

在早期的[[人工智慧]]研究中，為了實現類似人類的知識表示與自動推理，科學家們發展出了物件-屬性-值三元組（Object-Attribute-Value Triples）的概念。圖形在電腦中可以透過節點與邊的列表來表示，因此語意網絡能夠精確地對現實世界的知識進行結構化建模。

## 知識表示與三元組

語意網絡的核心基礎通常是**物件-屬性-值三元組**或**屬性-值對**。例如，在描述特定程式語言時，可以建立如下的三元組結構：

| 物件 | 屬性 | 值 |
|---|---|---|
| Python | 是 | 無型別程式語言 |
| Python | 發明者 | Guido van Rossum |
| Python | 區塊語法 | 縮排 |

這種以三元組為基礎的表示法，不僅能夠描述簡單的靜態數據，還能進一步擴展為更複雜的知識庫與本體系統。

## 相關應用與演進

語意網絡的概念與專家系統、[[自然語言處理]]以及後來的語意網有著密不可分的聯繫。在語意網的架構中，所有的概念都利用全球唯一的 URI 識別符號進行標識，進而形成跨網際網路的分散式知識階層。相關的技術標準如資源描述框架（RDF）與本體網路語言（OWL），都是基於類似語意網絡的三元組原理來建構形式化的知識體系。

雖然現代的[[機器學習]]與[[深度學習]]在許多領域取得了巨大成功，但語意網絡與符號式方法在需要高度透明性、可解釋性以及明確邏輯推理的任務中，依然扮演著不可或缺的角色。
